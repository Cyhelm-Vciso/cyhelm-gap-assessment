# CyHelm Gap Navigator

An evidence-linked readiness assessment demonstrating weighted progress, mutable assessment status, evidence quality, remediation priorities, JSON export, and optional AI evidence challenge.

Run `npm start`, then open `http://127.0.0.1:4173`. The assessment works without AI.

Optional AI supports any OpenAI-compatible hosted or local endpoint through `CYHELM_AI_BASE_URL`, `CYHELM_AI_MODEL`, and optional `CYHELM_AI_API_KEY`.

The demo contains a small CyHelm-authored sample profile and does not determine certification or regulatory compliance.
